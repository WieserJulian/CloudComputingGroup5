We are planning to build a cloud-based game server platform using Pterodactyl and Docker, allowing game servers to be automatically deployed and managed.

The main focus of our project is Monitoring, Security.

- Monitoring: We will use OpenTelemetry, Prometheus, and Grafana to collect and visualize metrics from our infrastructure and game servers.
- Security: We will use Falco to detect suspicious activities and potential security threats within containers.

The project covers topics: Cloud-native Applications, Continuous Integration, and Operations.
